# Java To-Do List 📝

Um sistema simples de lista de tarefas feito em Java, rodando no terminal.

## 🚀 Funcionalidades
- Adicionar nova tarefa
- Listar todas as tarefas
- Marcar tarefa como concluída
- Remover tarefa

## 🛠️ Tecnologias
- Java 17
- IntelliJ IDEA
- Programação Orientada a Objetos

## ▶️ Como rodar
1. Clone o repositório:
`git clone https://github.com/kaua-santos-dev/java-todo-list.git`
2. Abra no IntelliJ
3. Rode a classe `Main.java`
